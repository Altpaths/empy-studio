تعریف محصول

Empy Studio یک محصول مستقل برای ارکستراسیون توسعه نرم‌افزار با کمک چند موتور هوش مصنوعی است. Codex، Claude و Gemini فقط Driver هستند؛ مرکز محصول Empy است.

کاربر نباید JSON بنویسد، مسیرها را دستی وارد کند، Agent انتخاب کند، Context بسازد یا از Terminal برای کار روزمره استفاده کند.

قوانین غیرقابل نقض

۱. هیچ تیکتی خارج از این Roadmap ساخته نمی‌شود مگر با اصلاح رسمی همین فایل.
۲. هیچ تیکتی فقط برای افزایش تعداد ماژول‌ها یا تست‌ها پذیرفته نیست؛ باید ارزش قابل مشاهده برای کاربر ایجاد کند.
۳. Empy مستقل است؛ AI Providerها فقط Driverهای قابل تعویض‌اند.
۴. رابط اصلی نسخه ۱ Desktop است؛ CLI فقط ابزار پشتیبان و توسعه باقی می‌ماند.
۵. کاربر درخواست طبیعی می‌نویسد؛ Empy آن را به Task Contract تبدیل می‌کند.
۶. هر Agent فقط Context لازم، فایل‌های مجاز و بودجه مشخص دریافت می‌کند.
۷. Agentها اجازه ویرایش هم‌زمان یک فایل را ندارند مگر از مسیر Sync.
۸. تغییرات بدون Verification و Evidence قابل نهایی‌شدن نیستند.
۹. Commit، Push، Merge و Release بدون تأیید صریح کاربر انجام نمی‌شود.
۱۰. هر تیکت فقط وقتی کامل است که روی پروژه واقعی قابل مشاهده و قابل آزمایش باشد.
۱۱. Refactor نامرتبط، بازنویسی معماری و Feature creep ممنوع است.
۱۲. هر بار قبل از شروع کار باید «تیکت بعدی مجاز» در بالای همین صفحه بررسی شود.
