# Contributor Covenant Code of Conduct

We are committed to a harassment-free and inclusive community.

Expected behavior includes respectful communication, constructive feedback, empathy, and focus on what is best for the project and community. Harassment, discrimination, personal attacks, doxxing, and abusive behavior are not acceptable.

Project maintainers may remove, edit, or reject contributions and participation that violate these standards. Report conduct concerns privately to the maintainers using the contact method published by the repository owner.

This document is adapted from the Contributor Covenant, version 2.1.
