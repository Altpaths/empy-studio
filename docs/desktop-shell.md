# Desktop Shell

## Roadmap position

Phase 2, Ticket 4 of `EMPY_PRODUCT_MASTER_PLAN.html`.

## User-visible value

Empy Studio now has a desktop window with Home, Projects, Runs, Settings, an
Open Project entry point, and a visible workspace location.

## Scope boundary

Ticket 4 intentionally does not implement the Finder project picker, project
detection, task intake, planning, AI execution, verification, or diff review.

## Development launch

```text
empy-desktop
```

or:

```text
python -m empy_studio.desktop
```

A macOS development `.app` bundle is also included in `dist/`.
