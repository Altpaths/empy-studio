# Project Picker and Project Home

## Roadmap position

Phase 2, Ticket 5 of `EMPY_PRODUCT_MASTER_PLAN.html`.

## User-visible value

The user can now:

1. Open Empy Studio.
2. Click **Open Project**.
3. Choose a folder with the macOS Finder dialog.
4. Let Empy detect the project type.
5. Save the project in Workspace.
6. Reopen it from Recent Projects.
7. See a Project Home summary.

## Supported detection

- Laravel
- Python
- Node
- Rust
- Go
- Generic projects

## Project Home

The summary displays:

- project name and absolute path;
- detected project type;
- package manager;
- test availability;
- Git availability;
- framework markers.

## Scope boundary

Ticket 5 does not create Tasks, build execution plans, run AI drivers,
verify changes, or review diffs. The disabled **Create Task** button marks
the next roadmap capability.
