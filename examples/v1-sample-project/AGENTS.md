# Empy Studio v1 Sample Project

Work only inside this example project and its configured output directory.

Rules:

1. Read `task-contract.json` before execution.
2. Treat `input/customer-request.md` as the authoritative user request.
3. Do not access the network.
4. Do not modify files outside the output directory.
5. Produce both `result.json` and `evidence.json`.
6. Do not mark the task complete unless all acceptance criteria pass.
