# Roadmap

Empy Studio follows a narrow roadmap: make agent-assisted product delivery easier and cheaper without turning the control layer into another large platform.

## v0.1 — Developer Preview

- task graph and execution waves
- file ownership conflict detection
- runtime-aware verification
- validated learning
- agent-neutral CLI
- operating and contribution contracts

## v0.2 — Project Vault workflow

- vault initialization
- baseline manifest
- project map generation
- durable decision and release records
- context-package generation for worker agents

## v0.3 — Release workflow

- handoff validation
- synchronized release builder
- checksums and release manifest
- adapter contract for coding-agent hosts

## Before v1.0

- stable schemas and CLI contracts
- execution on multiple independent real projects
- measured context and token reduction
- security review
- reliable upgrade and migration guidance

Features that do not reduce context, repeated work, risk, or delivery friction will remain outside the core.
